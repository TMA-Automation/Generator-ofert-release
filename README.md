# Generator ofert — wydania

Pliki do pobrania i informacja o wersji aplikacji **Generator ofert** (TMA Automation,
Dział sprzedaży). Kod źródłowy znajduje się w prywatnym repozytorium.

## Pobieranie

Najnowszy plik `GeneratorOfert.exe` jest w zakładce **Releases**.
Instrukcja instalacji i obsługi: [DYSTRYBUCJA.md](DYSTRYBUCJA.md).

## Moduły

- **Update offer value** — odczytuje wartość końcową kontraktu z plików ofert
  (`OFFER*.xlsm`) i po przejrzeniu w tabeli aktualizuje pole `OFFER VALUE`
  w zadaniach ClickUp.

Plik `version.txt` służy aplikacji do sprawdzania dostępności aktualizacji.
